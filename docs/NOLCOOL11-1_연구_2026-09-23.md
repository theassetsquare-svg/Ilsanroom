## 0. 이 연구가 명세를 어떻게 바꿨나 (다섯 줄)
1. **FAQ 리치 결과는 2026-05 에 끝났고 사이트링크 검색창은 2024-11 에 끝났다** → FAQPage·SearchAction 은 해는 없지만 노출 장치가 아니다. 완독 뼈대의 FAQ 는 사람용.
2. **구글 AI 개요·AI 모드는 추가 요건 0** → AI 노출 조건 = 색인 + 스니펫 허용(max-snippet:-1 유지) + 사람에게 보이는 본문. llms.txt 는 구글이 무시(다른 AI 서비스용으로만 유지).
3. **보이지 않는 콘텐츠를 마크업하면 안 된다 + 클로킹 정의** → 466쪽 숨김 SSR 블록(1px clip)은 11-2 에서 보이는 본문으로 바꾼다.
4. **LCP 그림 지연 로드 금지·2.5초** → 첫 그림 lazy 356쪽은 11-3 즉시 고침.
5. **법**: 청소년=19세 미만·유흥주점은 출입금지업소(청소년보호법) · 광고성 알림은 사전 동의+야간 별도 동의(정보통신망법 §50) · 최소 수집·14세 미만 차단(개인정보보호법 §16·§22의2) · 거짓·과장 금지(표시광고법 §3) · 추천 보상은 경제적 이해관계 공개(심사지침) → 명세 「회원」줄의 근거.
